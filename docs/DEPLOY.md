# Deploying the dashboard

The dashboard is a static site in `site/`:

- `index.html`, `style.css`, `js/*.js`: vanilla ES modules, canvas, SVG, and three.js from jsDelivr for the 3D city
- `data/world.js` and `data/traces.js`: generated by `python -m holdworld run`

## Vercel

1. Run the pipeline locally so `site/data/` is fresh:
   ```bash
   python -m holdworld fetch-data && python -m holdworld test && python -m holdworld run
   ```
2. Commit `site/data/world.js`, `site/data/traces.js` and `results/`, then push to GitHub.
3. In Vercel: **Add New → Project → import the repo**.
   - If HoldWorld is the repo root, `vercel.json` already sets `outputDirectory` to `site`.
   - If it lives in a subfolder, set **Root Directory** to that folder.
   - Framework preset: **Other**. No build command, no environment variables, no API keys.
4. Open the deployment and press **Take the tour** (or add `#tour` to the URL).

The raw 1999 dataset is never uploaded. The site ships only results derived from it, with the acknowledgement its terms ask for.

## Local preview

```bash
python -m http.server 8030 --directory site
```

ES modules don't load from `file://`, so use a local server.
